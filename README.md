# 토리 일기장

책을 만 권 넘게 읽은 하얀 인형 토리(스토리)가 아이 일기의 첫 번째 독자가 되어 주는 일기 앱입니다.
초등학교 3학년 아이가 숙제가 아니라 재미있는 습관으로 일기를 쓰도록 만들었습니다.

- 설치 없이 웹 주소로 열립니다. 홈 화면에 추가하면 앱처럼 쓸 수 있고, 인터넷이 없어도 열립니다.
- 아이 일기는 그 기기 안에만 저장됩니다. 서버도, 인공지능 서비스도 쓰지 않습니다.
- 자세한 설계(토리 말투, 화면, 문구머니 규칙과 근거)는 [docs/DESIGN.md](docs/DESIGN.md)에 있습니다.

## 1. 처음 한 번: 웹 주소 열기 (GitHub Pages)

1. GitHub에서 이 저장소를 엽니다: https://github.com/bominpark-droid/tori-diary
2. 위쪽 <Settings> → 왼쪽 <Pages>를 누릅니다.
3. <Build and deployment>의 Source를 <Deploy from a branch>로 두고, Branch를 <main>, 폴더를 <(root)>로 고른 뒤 <Save>를 누릅니다.
4. 몇 분 뒤 아래 주소가 열립니다.

   **https://bominpark-droid.github.io/tori-diary/**

이후에는 저장소의 main에 고친 내용이 올라갈 때마다 몇 분 안에 자동으로 바뀝니다. 앱은 다음에 열 때 새 파일을 받습니다.

## 2. 아이 기기에 앱처럼 놓기

- 아이폰, 아이패드: 사파리로 주소를 연 뒤 아래쪽 공유 단추 → <홈 화면에 추가>
- 안드로이드: 크롬으로 연 뒤 오른쪽 위 점 세 개 → <홈 화면에 추가> 또는 <앱 설치>

같은 안내가 앱의 보호자 화면 → 저장과 백업에도 있습니다.

## 3. 기록과 개인정보

| 무엇 | 어디에 |
|---|---|
| 일기, 문구머니, 설정 | 그 기기 브라우저의 localStorage (`tori-diary:v1`) |
| 손글씨 사진 | 그 기기 브라우저의 IndexedDB (`tori-diary-photos`) |
| 다듬기 제안 | 기기 안에서 규칙으로 계산 (`js/feedback.js`). 글이 밖으로 나가지 않음 |
| 말하기 입력 | 기본으로 꺼져 있음. 켜면 목소리가 브라우저 회사(구글, 애플 등)의 음성 인식 서버로 갈 수 있음 |

꼭 알아 둘 것:

- 기록은 기기에만 있으므로 브라우저 기록을 지우거나 기기를 바꾸면 사라집니다. 보호자 화면 → <파일로 내보내기>로 가끔 백업해 두세요. 다른 기기에서는 <파일 가져오기>로 되살립니다.
- 아이폰 사파리에서는 사파리를 쓰는 동안 이 사이트를 7일 넘게 열지 않으면 저장된 기록이 지워질 수 있습니다(애플 WebKit의 저장 공간 정책). 홈 화면에 추가한 앱은 따로 계산되므로 홈 화면에 추가해서 쓰는 것을 권합니다. 보호자 화면의 <저장 공간 보호 요청>도 눌러 두세요.
- 이 저장소는 공개입니다. 앱 코드와 토리 사진(`assets/tori-photo.jpg`)은 누구나 볼 수 있습니다. 아이 일기는 저장소에 올라가지 않습니다. 사진을 내리고 싶으면 Claude에게 <토리 사진을 앱에서 빼 줘>라고 말하면 됩니다(사진이 없으면 그림 토리가 대신 나옵니다).

## 4. 보호자 화면

설정 탭 맨 아래 <보호자 화면>. 처음 들어갈 때 PIN 4자리를 정합니다.

- 이번 주 숫자(쓴 날, 다듬기를 누른 날과 고친 날, 문구점에 머문 시간 등). 글 내용은 나오지 않습니다.
- 아이가 <보여 줄래>를 고른 일기만 읽고 한 줄 답장을 남길 수 있습니다.
- 다듬기 도우미, 말하기 입력, 최대 음량, 쉬는 시간대, 문구머니 지급 방식(매일 또는 주간 정산), 백업.
- PIN을 잊었을 때: PIN 칸 아래 <PIN을 잊었어요>를 누르고 `보호자가 PIN을 새로 정합니다`를 그대로 입력하면 PIN을 새로 정할 수 있습니다.
- 보호자는 문구머니를 주거나 뺄 수 없습니다(보상이 그날 기분에 따라 바뀌지 않게 하려는 설계).

## 5. 문구머니 규칙 (요약)

- 그날 첫 일기를 다 쓰면 1,000원.
- 다듬기에서 토리 제안을 보고 글을 고치면 다듬기 보너스 1,000원(하루 한 번, 첫 회차). 보기를 고르든 자기 말로 쓰든 똑같이 인정합니다.
- 같은 날 두 번째 일기부터는 문구머니 없이 저장됩니다.
- 문구점: 22개 상품, 3,000~18,000원. 뽑기, 확률, 한정 판매, 카운트다운, 연속 기록은 없습니다.

## 6. 바이브코딩으로 고치기

Claude에게 하고 싶은 것을 그대로 말하면 됩니다. Claude는 이 저장소의 [CLAUDE.md](CLAUDE.md)를 먼저 읽고 고칩니다.

예:

- 문구점에 공룡 스티커 6개 묶음을 3,000원으로 넣어 줘.
- 주제 카드에 <오늘 급식에서 제일 맛있었던 것> 카드를 더해 줘.
- 토리가 일기를 다 읽고 하는 칭찬 말을 더 다양하게 해 줘.
- 맞춤법 사전에 <어의없다 → 어이없다>를 넣어 줘.
- 아이가 <스티커 칸이 4개라 모자라>래. 6개로 늘려 줘.

문구머니 금액, 보너스 조건처럼 처음에 보호자가 정한 것(설계서의 <사용자 결정>)을 바꾸는 요청이면 Claude가 한 번 더 확인합니다.

## 7. 개발자용

- 만드는 단계가 없는 정적 웹앱입니다(HTML, CSS, 자바스크립트 모듈). 파일을 고치고 올리면 끝입니다.
- 내 컴퓨터에서 보기: 저장소 폴더에서 `npm run serve` (= `python3 -m http.server 8080`) 후 http://localhost:8080
- 시험: `npm test` (Node 22 이상). 다듬기 규칙, 문구머니, 날짜, 파일 점검(빠진 파일, 문법 실수, 쓰지 않는 말)을 확인합니다.

| 폴더 | 내용 |
|---|---|
| `index.html`, `sw.js`, `manifest.webmanifest` | 앱 뼈대, 오프라인 준비, 홈 화면 앱 정보 |
| `css/` | 색과 글꼴(`tokens.css`), 기본 모양, 그림, 화면별 모양 |
| `js/screens/` | 화면 하나에 파일 하나 |
| `js/data/` | 토리 대사, 주제 카드, 상품표, 맞춤법 사전, 시범 일기 |
| `js/art/` | 표지와 스티커 그림(SVG) |
| `js/feedback.js` | 다듬기 도우미 규칙 |
| `js/rewards.js` | 문구머니 규칙 |
| `docs/DESIGN.md` | 설계서 |
| `tests/` | 자동 시험 |
